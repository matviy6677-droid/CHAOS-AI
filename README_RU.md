# CHAOS AI v0.2 — локальный космический чат

Мрачный чёрно-фиолетовый интерфейс, история чатов, ролевой режим, локальное хранение, экспорт резервной копии и подключение локальной модели через Ollama. API-ключ не нужен.

> Это экспериментальная версия. Для ответов настоящей модели нужны Node.js, Ollama и скачанная модель. Без них интерфейс откроется, но чат покажет подсказку об отключённом движке.

## 1. Что понадобится

- Windows 10/11
- Node.js LTS (рекомендуется Node.js 20 или новее): https://nodejs.org/
- Ollama для Windows: https://ollama.com/download/windows
- Свободное место для модели. Для `qwen2.5:3b` ориентируйся примерно на 2–3 ГБ с учётом файлов и кэша.

## 2. Установи локальную модель

Установи Ollama и открой PowerShell. Выполни:

```powershell
ollama pull qwen2.5:3b
```

Проверить список моделей:

```powershell
ollama list
```

Модель загружается из интернета один раз, а затем запускается локально. Скорость зависит от компьютера.

## 3. Запуск CHAOS AI

Распакуй ZIP в отдельную папку, например `C:\CHAOS_AI_v0.2`. Не удаляй старый проект JARVIS.

Открой терминал в папке проекта и выполни:

```powershell
npm install
npm run server
```

Оставь это окно открытым. Во втором терминале в той же папке выполни:

```powershell
npm run dev
```

Открой адрес, который покажет Vite — обычно `http://127.0.0.1:5173`.

## 4. Сборка

```powershell
npm run build
npm run preview
```

Это создаёт статический фронтенд в `dist`. Для работы ИИ нужен отдельный backend и Ollama. `dist` сам по себе не включает модель.

## 5. Как работает приватность

- История хранится в `localStorage` браузера на этом компьютере.
- Текст чата отправляется локальному backend на `127.0.0.1`, а затем Ollama на `127.0.0.1:11434`.
- Встроенные иллюстрации используют внешний Pollinations URL и требуют интернет; промпт сцены передаётся этому сервису. Не считай генерацию изображений полностью локальной.
- Не открывай backend в интернет без отдельной защиты и не выставляй порт Ollama наружу.

## 6. Размещение в интернете и раздача друзьям

ZIP можно передать друзьям как исходный проект. Им понадобятся Node.js, Ollama и модель.

Фронтенд можно собрать и разместить на статическом хостинге (например, Netlify или Vercel), но текущий backend намеренно слушает только `127.0.0.1` и не является публичным сервером. Если выложить только фронтенд, удалённые пользователи не смогут обратиться к твоему локальному Ollama. Для общей онлайн-версии понадобится развёрнутый backend/сервер модели, HTTPS, ограничения запросов и защита от злоупотреблений. Не публикуй приватный компьютер как сервер без помощи взрослого, который понимает сетевую безопасность.

## 7. Диагностика

- Проверка backend: открой `http://127.0.0.1:8787/api/health` при работающем `npm run server`.
- Проверка Ollama: в PowerShell выполни `ollama list`.
- Если сервер не найден — проверь, что оба терминала остаются открытыми.
- Если модель не найдена — выполни `ollama pull qwen2.5:3b`.
- Если порт занят, закрой старый экземпляр сервера или измени `PORT` в окружении.
